Placeholder for contribution guide instructions

## Documentation

### Backend

- Activating virtual environment:
```bash
cd backend
source .venv/bin/activate
```
- Running development server:
```bash
cd backend
uv run fastapi dev
```
- FastAPI Doc Endpoints:
  - SwaggerUI: use `/doc`
  - Redoc: use `/redoc`

### Frontend

- Development mode:
```bash
cd frontend
npm run dev
```
